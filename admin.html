🐙 บันทึกขึ้น GitHub
push CSV ที่โหลดอยู่ในเบราว์เซอร์ขึ้นรีโปผ่าน GitHub API
วิธีใช้: 1) ใส่ข้อมูลรีโปและ Token → 2) กด ทดสอบ → 3) กด ⬆ บันทึกขึ้น GitHub
Token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained · เลือกรีโปนี้ · Contents = Read and write
หมายเหตุ: Token เก็บในเบราว์เซอร์เท่านั้น — ข้อมูลบนเว็บจริงเปลี่ยนได้ก็ต่อเมื่อมี token ที่มีสิทธิ์เขียนเท่านั้น
